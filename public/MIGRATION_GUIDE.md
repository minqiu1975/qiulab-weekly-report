# QiuLab周报分析系统 - 网站迁移指南

## 方案一：云端同步路径（推荐，最简单）

**前提**：原网站已启用云端同步（Supabase）

### 步骤

1. **在原网站确认云端同步已启用**
   - 打开 设置 → 系统配置 → 云端同步
   - 确认状态显示"已同步"

2. **部署网站到新托管平台**
   - 将 `dist/` 目录中的所有文件上传到新托管平台
   - 新平台只需要支持静态文件托管（HTML/CSS/JS）

3. **在新网站登录**
   - 打开新网站地址
   - 用密码 QiuLab2026 登录
   - 进入 设置 → 系统配置
   - 确认 Supabase 云端同步配置已自动载入

4. **点击"立即同步"**
   - 数据会自动从 Supabase 云端拉取
   - 所有成员、趋势、深度分析、上传历史全部恢复

**优点**：全自动，数据实时同步
**缺点**：需要云端同步之前已启用

## 方案二：JSON 导出导入路径（最可靠）

**适用场景**：任何情况，包括未启用云端同步

### 步骤 A：在原网站导出数据

1. 在原网站打开 **设置 → 系统配置 → 数据迁移**
2. 点击 **"导出 JSON"** 按钮
3. 浏览器会下载一个文件：`qiulab-data-YYYY-MM-DD.json`
4. 妥善保存这个文件（这就是你的全部数据）

### 步骤 B：部署网站到新托管平台

1. 获取构建产物 `dist/` 目录：
   ```bash
   # 如果本地有源码
   npm run build
   
   # dist/ 目录包含：
   # - index.html          (入口页面)
   # - seed-deep-analyses.json  (预生成分析数据)
   # - assets/             (JS/CSS/图片)
   ```

2. 将 `dist/` 中的所有文件上传到新静态托管平台

### 步骤 C：在新网站导入数据

1. 打开新网站地址
2. 用密码 QiuLab2026 登录
3. 进入 **设置 → 系统配置 → 数据迁移**
4. 点击 **"导入 JSON"**
5. 选择之前下载的 `qiulab-data-YYYY-MM-DD.json` 文件
6. 导入成功后会自动刷新页面
7. 所有数据完整恢复

**导出的数据包含**：
- 全部 32+ 位成员信息
- 所有动态趋势数据（上传的周报分析结果）
- 所有深度分析结果（Kimi AI 生成）
- 上传历史记录
- 系统设置（API Key、云端配置等）

**优点**：不依赖云端，最可靠
**缺点**：需要手动导出和导入

## 方案三：纯文件复制（最简单，但只含预置数据）

**适用场景**：快速部署，不迁移用户上传的数据

1. 将 `dist/` 目录中的所有文件复制到新托管平台
2. 预置的 32 人分析数据通过 `seed-deep-analyses.json` 自动载入
3. 用户上传的周报分析数据需要重新上传

---

## 关键数据清单

| 数据项 | localStorage Key | 说明 |
|--------|-----------------|------|
| 团队成员 | `qlab_persons_v5` | 所有成员信息 |
| 动态趋势 | `qlab_dynamic_trends` | 上传周报后的趋势数据 |
| 动态历史 | `qlab_dynamic_history` | 周报摘要历史 |
| 动态标签 | `qlab_dynamic_labels` | 趋势图 X 轴日期标签 |
| 上传日期 | `qlab_uploaded_dates` | 已上传周报日期（重复检测）|
| 深度分析 | `qlab_deep_analyses` | Kimi AI 深度分析结果 |
| 上传历史 | `qlab_uploads` | 上传文件历史记录 |
| API Key | `qlab_moonshot_api_key` | Kimi API Key（如有自定义）|
| API URL | `qlab_moonshot_api_url` | API 端点配置 |
| 云端配置 | `qlab_sync_config` | 云端同步开关状态 |
| 云端凭据 | `qlab_provider_config` | Supabase 凭据 |
| 百度网盘 | `qlab_baidu_token` | 百度网盘 token |
| 系统设置 | `qlab_settings` | 其他系统设置 |

## 新托管平台要求

- **纯静态托管**即可（HTML/CSS/JS）
- 支持 **SPA 路由**（HashRouter，无需服务器配置）
- 无需后端、数据库、Node.js
- 推荐平台：Cloudflare Pages、Vercel、Netlify、GitHub Pages、阿里云 OSS

## 注意事项

1. **数据安全**：导出的 JSON 文件包含 API Key 等敏感信息，妥善保管
2. **浏览器差异**：不同浏览器的 localStorage 不互通，换浏览器需要重新导入
3. **云端同步**：迁移后建议在新环境重新启用云端同步，确保后续自动同步
